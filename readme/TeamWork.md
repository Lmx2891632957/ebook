# 团队分工文档 —— 基于STM32的电子书阅读器

## 项目概况

| 维度 | 详情 |
|------|------|
| **硬件平台** | 正点原子 STM32F103 Mini 开发板（MCU: STM32F103RCT6, 256KB Flash, 48KB SRAM） |
| **外设** | 2.8" TFT LCD (320x240, 电阻触摸) + MicroSD (SPI) + 8MB SPI Flash |
| **软件栈** | UCOS-II RTOS + FATFS R0.11 + 正点原子 GUI 控件库 + BSP 驱动层 |
| **应用代码量** | ebook.c (~1883行) + ebook_bookmark.c (~365行) + common.c (~1309行) ≈ 3500行 |
| **总固件大小** | Code=102KB, RO-data=49KB, RW-data=672B, ZI-data=46KB |

## 三人分工方案

### 👤 A 同学：核心阅读引擎 + 系统集成

**角色定位**：负责电子书最核心的文本读取、排版渲染引擎，以及整体系统集成。

**负责模块：**

| 模块 | 关键文件 | 技术要点 |
|------|----------|----------|
| 文本分段读取引擎 | `User/APP/ebook.c` — `ebook_scan_page_forward()` | FATFS `f_lseek` + `f_read` 按需读取，避免大文件一次性载入导致内存溢出 |
| GBK 排版引擎 | `User/APP/ebook.c` — `ebook_draw_page()` | GBK 双字节边界检测（首字节 >= 0x81，尾字节 >= 0x40），自动换行算法，半字截断防护 |
| 翻页逻辑 | `User/APP/ebook.c` | 触摸滑动手势识别（dx/dy 阈值 50px，水平主导判定），物理按键翻页（KEY1/WK_UP），历史页栈回溯（40 条记录） |
| 内存管理 | `User/APP/ebook.c` + `ebook.h` — `ebook_ctx_t` | 48KB SRAM 约束下，堆分配上下文结构体（~216B），FIL 对象堆分配（~544B），Page buffer 分段复用 |
| 系统启动与任务编排 | `User/main.c` | UCOS-II 4 任务创建（start/main/usart/watch），SD 卡热插拔监控，系统初始化全流程 |

**对应 PRD 条目**：基础#1（文本读取与显示）、基础#2（滑动翻页）、扩展#4（中英文读取）

**答辩可讲的技术亮点**：
- GBK 编码的半字节边界处理算法 —— 如何在分段读取的 chunk 边界不切碎中文字符
- 分段读取策略解决 48KB SRAM 下大文件（>500KB）的内存瓶颈
- UCOS-II 多任务协同设计（GUI 任务/监控任务/调试任务的优先级划分）

### 👤 B 同学：人机交互界面 + 书签系统

**角色定位**：负责人机交互的全部 UI 界面、书签持久化功能、进度条控件。

**负责模块：**

| 模块 | 关键文件 | 技术要点 |
|------|----------|----------|
| 文件浏览器 | `User/APP/ebook.c` — State 0 | filelistbox 控件，目录层级导航（进入/退出），.txt 过滤器，双击打开书籍 |
| 书签持久化系统 | `User/APP/ebook_bookmark.c` | 独立 `.bmk` 文件（magic = 0x424D4B00），每书最多 10 条，±200 字节容差去重 |
| 书签首句提取 | `User/APP/ebook_bookmark.c` — `ebook_bm_extract_label()` | 从书签偏移处读取文本，截取首个有意义句子（遇到 `。？！…` 或换行符断句），最大 28 字节 GBK |
| 书签 UI 面板 | `User/APP/ebook.c` | 两级模态面板：Panel 1 列表浏览（添加/返回），Panel 2 操作选择（跳转/删除/取消） |
| 可拖动进度条 | `User/APP/ebook.c` + `Middlewares/GUI/progressbar.c` | 触摸拖动实时显示百分比标签，松手后对齐 GBK 边界再 `f_lseek` 跳转 |
| 字体切换面板 | `User/APP/ebook.c` | 3 按钮模态面板（12/16/24），切换后重建 memo 控件并重排整个页面 |
| 底部工具栏 | `User/APP/ebook.c` | 5 按钮布局（返回/字体/书签/护眼/亮度），模态面板弹出/销毁状态机 |

**对应 PRD 条目**：基础#3（选书界面）、基础#4（字体调节）、基础#5（书签功能）、扩展#1（可拖动进度条）

**答辩可讲的技术亮点**：
- 书签首句自动提取算法 —— GBK 标点符号检测，从页面起始偏移找到第一条完整语义句
- 两级模态面板的 UI 状态机设计 —— Panel 列表 / Panel 操作 / 直接返回，状态清晰无泄漏
- 进度条拖动时 GBK 边界对齐策略 —— 避免 `f_lseek` 跳转到汉字中间导致后续页面乱码

### 👤 C 同学：硬件驱动适配 + 显示与背光控制

**角色定位**：负责所有底层硬件驱动适配、显示优化、背光 PWM 控制、背景色切换。

**负责模块：**

| 模块 | 关键文件 | 技术要点 |
|------|----------|----------|
| LCD 显示驱动 | `Drivers/BSP/LCD/lcd.c` | 16 位并行接口（GPIOB 数据总线 + GPIOC 控制线），ILI9341/ST7789/NT35310 多控制器自动识别，DMA 加速窗口填充 |
| 触摸驱动与校准 | `Drivers/BSP/TOUCH/touch.c` | XPT2046 软件 SPI（GPIOC 位带操作），5 点校准 + 仿射变换，触摸坐标滤波去抖 |
| **软件 PWM 背光** | `User/APP/ebook.c` — TIM3 ISR | **核心亮点**：PC10 引脚无定时器复用功能，纯软件方案——TIM3 @ 3kHz + 3 步子计数器 = 1kHz 有效 PWM，BSRR 寄存器原子操作，NVIC 最低优先级（15）防干扰 UCOS-II 调度 |
| 三档亮度调节 | `User/APP/ebook.c` | 暗（33%）/ 中（66%）/ 亮（100%）占空比，底部栏亮度按钮 + 3 选项模态面板 |
| 护眼模式 | `User/APP/ebook.c` | 背景色一键切换（白色 0xFFFF ↔ 护眼黄 `EYECARE_BG` 0xFFF0），全区域重绘避免残留 |
| SD 卡 SPI 通信 | `Drivers/BSP/SDMMC/spi_sdcard.c` | 硬件 SPI1（PA5/PA6/PA7 + PA3 CS），SDv1/v2/SDHC 兼容，卡检测与热插拔 |
| FATFS 文件系统 | `Middlewares/FATFS/` | code page 936（GBK 中文），长文件名支持，多磁盘挂载（SD 卡 + SPI Flash） |
| 系统时钟与初始化 | `Drivers/SYSTEM/` | 72MHz PLL 配置，SysTick 精确定时，GPIO 时钟使能管理 |

**对应 PRD 条目**：扩展#3（背景色可调 + 亮度可分档调节）

**答辩可讲的技术亮点**：
- **软件 PWM 是最大加分项**：PC10 引脚在 STM32F103RCT6 上仅复用为 USART3_TX，无定时器通道，传统方法无法做硬件 PWM。通过 TIM3 中断 + BSRR 原子操作 + 子计数器降频，在不占用硬件定时器通道的前提下实现了纯软件 PWM 调光，且 NVIC 优先级设为最低（15）确保不干扰 UCOS-II 实时调度
- 电阻触摸的 5 点校准算法与仿射变换矩阵
- 三种 LCD 控制器（ILI9341/ST7789/NT35310）自动识别与适配

## 答辩建议

1. **A 同学先讲**（约 3-4 分钟）：系统全景（分层架构图）→ 核心引擎技术难点（GBK 排版算法、分段读取策略、翻页逻辑），定下技术基调
2. **B 同学接上**（约 3-4 分钟）：在 A 的排版引擎之上，展示交互层 —— 怎么选书、怎么调字体、书签怎么存怎么跳、进度条拖动体验
3. **C 同学收尾**（约 3-4 分钟）：展示硬件功底 —— **软件 PWM 是最大的加分项**（"PC10 没有定时器通道，我们怎么做的？"），LCD/触摸/SD 卡三件套的驱动适配，以及系统如何从裸机启动到 RTOS 运行
4. **留 3 分钟**给老师提问和实物演示

**向老师展示的关键实物操作流程**：
- 从 SD 卡选书 → 进入阅读 → 左右滑动翻页
- 底部工具栏依次展示：字体调节（12/16/24）→ 书签添加与跳转 → 护眼模式切换 → 亮度三档调节
- 拖动进度条跳转到大文件的不同位置
- 串口终端展示后台任务运行状态（内存使用、SD 卡热插拔检测）
